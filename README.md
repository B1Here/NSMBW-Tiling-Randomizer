# NSMBW Tiling Randomizer

[![Latest Release][release-version-image]][releases-url] ![Repo Stars][stars-image]

A silly little Python tool to help with creating random object patterns for NSMBW levels.

## Requirements

- Python 3.12+
- PyQt6

## Usage

Run [`tiling_randomizer.bat`](tiling_randomizer.bat) or the [`tiling_randomizer.py`](src/tiling_randomizer.py) script to launch the application. Load a template provided in [`templates/`](templates/) to get started. Define width and height as well as whether edges should be used and hit "Generate". The output will be shown in the "ReggieClip" field below the "Generate" button.

## Defining Your Own Templates

To define your own template use the designated "Template" tab. Make sure to have Reggie open on the side to help with choosing the correct object IDs plus their size.
